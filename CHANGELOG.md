# Changelog

## 0.1.0 — 2026-11-16

First public release.

- Local browser workspace with source text, findings, and a share preview.
- Common secret and personal-data detection with consistent placeholders.
- Per-occurrence keep/mask choices and custom private terms.
- Fictional samples and local text-file import, including drag and drop.
- Plain-text and Markdown copying and downloads.
- Dependency-free Node CLI with stdin, file input/output, secrets-only mode, custom terms, and a summary report.
- Automated tests, a static demo, and English/Chinese documentation.

Detection is heuristic; review output before sharing.
